# X2MD v4.1.0

X2MD 4.1 聚焦 X 长文章的翻译体验、文章工具栏稳定性和桌面设置界面的可用性。

> 本次 macOS 资产因 GitHub 环境缺少 Developer ID 与公证凭据，采用已通过本地发行烟测的 Electrobun ad-hoc 签名备用构建；该资产未使用 Developer ID 签名，也未经过 Apple 公证。

## 新增

- X 文章支持按段渐进式翻译，完成一个段落后立即替换显示，无需等待全文完成。
- 翻译结果缓存一小时，同一文章重复翻译时可直接复用。
- 打开标题不是简体中文的 X 文章时，默认自动翻译标题。
- X2MD App 的“网页按钮”设置新增“自动翻译 X 文章标题”开关，可随时关闭。
- X 视频支持从文章与推文页面下载，并保持现有安全下载边界。

## 修复与优化

- 修复 X 文章复制和翻译按钮在刷新、动态渲染或页面加宽扩展影响下消失、错位的问题。
- 移除文章页不需要的悬浮大按钮，操作入口稳定放在 X 原生工具栏区域。
- 修复部分 Grok 翻译响应带有额外 JSON 行时无法正确解析的问题。
- 修复推文翻译后超链接被拆分或失去可点击状态的问题，并保留原始链接目标与显示文本。
- 修复 macOS App 首次启动解包后丢失内置 Chrome 扩展目录的问题。
- 自动标题翻译不会覆盖复制、保存或全文翻译内容；点击全文翻译仍会从原始标题和正文继续处理。
- 修复 X2MD App 设置页 Logo 因内联页面相对路径失效而无法显示的问题。
- 修复“附件目录”和“嵌入格式”控件垂直错位，并改用轻量的现有 128×128 Logo 资源。
- 修复设置脚本仅转译未打包时，内联 App 页面无法加载依赖模块的问题。

## 升级说明

- App 与 Chrome 扩展建议同时升级到 4.1.0。
- 自动翻译 X 文章标题默认开启，可在 X2MD App →“网页按钮”中关闭。
- macOS 本地备用构建为 Electrobun ad-hoc 签名版本；正式 Tag 工作流具备凭据时会优先生成 Developer ID 签名并公证的版本。
